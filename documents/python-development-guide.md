# Гайд по Python-разработке

Краткая дорожная карта для тех, кто хочет создавать backend-приложения на Python.

## 1. Освойте базовый Python

Изучите и закрепите на практике:

- типы данных, переменные и операторы;
- условия, циклы и генераторы;
- функции, области видимости и декораторы;
- коллекции: `list`, `tuple`, `dict`, `set`;
- исключения и контекстные менеджеры;
- работу с файлами;
- классы, наследование и композицию;
- аннотации типов;
- модули, пакеты и виртуальные окружения;
- асинхронность: `async`, `await`, `asyncio`.

Не ограничивайтесь чтением. После каждой темы решайте небольшую задачу или создавайте
мини-проект.

## 2. Настройте инструменты

Минимальный набор Python-разработчика:

- Git и GitHub для контроля версий;
- IDE: PyCharm, VS Code или Cursor;
- `venv` для изоляции зависимостей;
- `pip` или `uv` для установки пакетов;
- Ruff для форматирования и проверки кода;
- Pytest для автоматических тестов;
- Docker для одинакового запуска приложения в разных окружениях.

Создание виртуального окружения:

```bash
python -m venv .venv
```

Активация в PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

## 3. Изучите backend-разработку

Разберитесь со следующими темами:

1. HTTP: методы, заголовки, коды ответов.
2. REST API и правила проектирования эндпоинтов.
3. JSON и валидация входных данных.
4. Аутентификация и авторизация.
5. Логирование и обработка ошибок.
6. Конфигурация через переменные окружения.
7. Синхронное и асинхронное выполнение.

Для первого API подойдет FastAPI. Для большого проекта со встроенной админкой можно
рассмотреть Django и Django REST Framework.

## 4. Научитесь работать с базами данных

Начните с SQL:

- `SELECT`, `INSERT`, `UPDATE`, `DELETE`;
- фильтрация, сортировка и группировка;
- `JOIN`;
- индексы;
- транзакции;
- ограничения и связи между таблицами.

Для учебных проектов подойдет SQLite. Для production-проектов часто используют
PostgreSQL. После основ SQL изучите SQLAlchemy и Alembic, но не заменяйте ими понимание
самого SQL.

## 5. Пишите поддерживаемый код

- Давайте сущностям понятные имена.
- Разделяйте бизнес-логику, работу с данными и внешний интерфейс.
- Делайте функции небольшими и решающими одну задачу.
- Добавляйте типы для публичных функций.
- Не храните пароли, токены и ключи в Git.
- Используйте `.env` локально и секреты платформы при развертывании.
- Проверяйте внешние данные до их использования.

## 6. Тестируйте

Полезная последовательность:

1. Unit-тесты для бизнес-логики.
2. Интеграционные тесты для базы данных и API.
3. Проверка основных пользовательских сценариев.

Тест должен быть независимым, воспроизводимым и проверять конкретное поведение.

Пример запуска:

```bash
pytest
```

## 7. Создайте портфолио

Подходящие проекты:

- Telegram-бот с базой данных;
- REST API для задач или заметок;
- сервис сокращения ссылок;
- каталог товаров;
- система бронирования;
- сервис уведомлений с очередью задач.

Для каждого проекта подготовьте:

- понятный README;
- инструкцию по запуску;
- пример `.env`;
- тесты;
- историю осмысленных коммитов;
- описание архитектурных решений.

## 8. Пример плана на 12 недель

- Недели 1–3: Python Core и задачи.
- Недели 4–5: Git, SQL и PostgreSQL.
- Недели 6–8: FastAPI или Django, создание API.
- Недели 9–10: тесты, Docker и логирование.
- Недели 11–12: итоговый проект, документация и развертывание.

## 9. Что изучать дальше

После уверенного освоения базы:

- Redis;
- очереди задач и брокеры сообщений;
- CI/CD;
- мониторинг;
- паттерны проектирования;
- безопасность веб-приложений;
- алгоритмы и структуры данных;
- основы Linux и сетей.

Главное правило: регулярно создавайте законченные проекты. Один работающий сервис с
тестами и документацией даст больше опыта, чем несколько незавершенных курсов.
